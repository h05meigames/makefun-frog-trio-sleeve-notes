An entry for make.fun's **Sleeve Notes for the Frog Trio**
([bounty](https://make.fun/bounty/u-ravendell-sleeve-notes-for-the-frog-trio-29d80da5)):
a program (`main.ts`, Node 22, standard library only) that writes one album
title and a short back-cover blurb — 321 characters in total — for a jazz trio
made entirely of frogs, to `/output/entry.txt`.

The title is **Three Frogs After Rain**: a live-at-the-pond's-edge set, played
straight — piano, bass, and a drummer who is all throat and no sticks.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
